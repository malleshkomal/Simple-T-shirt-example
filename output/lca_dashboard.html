How carbon data for three products moves from raw supplier, meter and shipping records into a clean star schema, and then into animated charts. Every number on this page comes from pipeline.py running on simulated data.

Step 2 · Data structure

Typed records in, star schema out

Inside the pipeline every flow becomes an InventoryRecord (product, stage, activity, amount, unit). Results load into a SQLite star schema: one fact table of impacts joined to four small dimension tables.

Step 4 · Visualization

Animated charts

Each chart animates once when the page loads. On a phone, swipe a chart sideways to see all of it. Hover over a bar or line for exact values, and use Replay to run the animation again.

Run it yourself

Four commands

# pip install pandas matplotlib
python collect.py     # step 1: write raw source files to data/raw/
python pipeline.py    # steps 2–3: validate, transform, calculate, load into lca.db and JSON
python visualize.py   # step 4: animated GIF charts in output/
python build_page.py  # step 4: this animated HTML page, output/lca_dashboard.html
